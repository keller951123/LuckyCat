## 動態互動效果

- 3D 視差傾斜：滑鼠移動時，展示台與象徵卡片會依游標位置傾斜。
- 點擊金幣特效：點擊網頁任意位置，會灑出「福、吉、財、旺、喵、💖」粒子。
- 點擊貓叫聲：點擊網頁任意位置、按鈕、籤筒、照片時，會播放 `貓叫聲.mp3`；連點時聲音可重疊，可用導覽列「音效」按鈕開關。
- 6 款姿態切換：招福揮手、愛心滿滿、開懷大笑、翻肚放鬆、守護毛帽、舔爪招財。
- 幸運寫真燈箱：點擊照片卡片可全螢幕放大，支援 Esc 與點背景關閉。
- 今日幸運籤筒：搖動動畫配合隨機生成金句、幸運色、幸運物與幸運數字。
- 漂浮貓咪腳印背景：Canvas 繪製的肉球腳印緩緩上浮、搖擺旋轉。
- 背景音樂：內建 `bgm.mp3`（小貓呼嚕聲）循環播放，瀏覽器若禁止自動播放，會在第一次點擊頁面後開始，可用導覽列按鈕開關。

## 執行方式

直接用瀏覽器開啟 `index.html` 即可。請確保 `index.html`、`style.css`、`script.js`、`bgm.mp3`、`貓叫聲.mp3` 放在同一個資料夾；音檔不需連網。

## 效能優化紀錄

- Canvas：腳印與點擊粒子改為預先繪製成小圖（sprite）再 `drawImage`，不再每幀做 `shadowBlur`；以時間差（dt）更新，60Hz / 120Hz 螢幕速度一致；分頁切到背景時自動暫停。
- CSS：移除卡片與導覽列的 `backdrop-filter`、背景光暈的 `blur(140px)`；把 `transition: all` 改為只動畫必要屬性；支援「減少動態效果」系統設定。
- 滑鼠傾斜：以 `requestAnimationFrame` 合併事件並快取元素位置，不再每次移動都重新量版面。
- 導覽列高亮：快取各區塊位置並節流，捲動時不再反覆讀取 `offsetTop`。
- 換造型：等圖片 `decode()` 完成後再淡入，切換不卡。
- 修正 `index.html` 中音效按鈕 `id` 的引號錯誤（原本音效開關無法作用）。
